0. تحميل المكتبة (Loadstring)

هذا هو رابط سكريبت المكتبة الخاص بك، يجب وضعه في بداية أي سكربت لكي تعمل معك الأكواد بشكل صحيح.

Loadstring Script 
local Library = loadstring(game:HttpGet("https://raw.githubusercontent.com/mmjjdok-lang/Rwonom-Hub-/refs/heads/main/Rwonom.%20Lua"))()

1. إنشاء النافذة الأساسية

هذا الكود لتحديد عنوان النافذة، الأيقونة، المقاس، والثيم العام.

Window Setup Code 
local Window = Library.CreateWindow({
    Title = "الواجهة الاحترافية",
    Icon = "home",        -- اسم أيقونة Lucide، تطلع يسار العنوان
    Theme = "Green",
    Size = { X = 586, Y = 339 },
})

2. إنشاء التبويبات والعناصر الداخلية

إليك طريقة إضافة تبويب رئيسي، نصوص عادية، ملاحظات بألوان مختلفة، وأزرار تفاعلية مع إشعارات.

Tabs & Elements Code 
local MainTab = Window:CreateTab("الرئيسية", "settings") -- أيقونة Lucide بالاسم
MainTab:CreateLabel("هذا نص بسيط بدون خلفية")
MainTab:CreateNote("هذه ملاحظة غامقة", "Dark")
MainTab:CreateNote("هذه ملاحظة زرقاء معلوماتية", "Blue")

MainTab:CreateButton("زر تجريبي", "يرسل إشعار عند الضغط", function()
    Library.Notify("تم", "تم الضغط على الزر", "وصف إضافي هنا", 3)
end)

3. نظام التدرج العام (Gradients)

تستطيع تطبيق تدرجات لونية مذهلة على زر الفتح أو الإطار الخارجي للنافذة مع التحكم بالسرعة والكثافة.

Gradient System Code 
-- نظام التدرج العام
Library.ApplyGradient(Window.OpenButton, { Colors = {"Green", "Purple"}, Speed = 5, Intensity = 1 })
Library.ApplyGradient(Window.FrameStroke, { Colors = {"Blue", "Cyan"}, Speed = 8, Intensity = 0.6 })
