Rwonom Library

Complete documentation and guide for setting up and customizing the UI library

1. Library Loadstring

Paste this code at the very top of your script to load the library core functions.

loadstring.lua 
local Library = loadstring(game:HttpGet("https://raw.githubusercontent.com/mmjjdok-lang/Rwonom-Hub-/refs/heads/main/Rwonom.%20Lua"))()

2. Creating the Window

Initialize the main window, set its title, Lucide icon, theme color, and dimensions.

window.lua 
local Window = Library:CreateWindow({
    Title = "Professional UI",
    Icon = "home",        -- Lucide icon name, appears on the left of the title
    Theme = "Green",
    Size = { X = 586, Y = 339 },
})

3. Creating Tabs

Create functional tabs inside your window using Lucide icon identifiers.

tab.lua 
local MainTab = Window:CreateTab("Main", "settings") -- Lucide icon by name

4. Labels & Notes Elements

Add simple text labels or highlighted notes to provide information to users.

labels_notes.lua 
MainTab:CreateLabel("This is a simple text without background")
MainTab:CreateNote("This is a dark note highlight", "Dark")
MainTab:CreateNote("This is an informative blue note", "Blue")

5. Buttons & Notifications System

Create interactive buttons that trigger custom notifications upon clicking.

buttons.lua 
MainTab:CreateButton("Test Button", "Sends a notification when clicked", function()
    Library.Notify("Success", "Button was clicked!", "Additional description here", 3)
end)

6. Global Gradient System

Apply animated color gradients to open buttons or frame strokes with custom speed and intensity.

gradients.lua 
-- Global Gradient System
Library.ApplyGradient(Window.OpenButton, { Colors = {"Green", "Purple"}, Speed = 5, Intensity = 1 })
Library.ApplyGradient(Window.FrameStroke, { Colors = {"Blue", "Cyan"}, Speed = 8, Intensity = 0.6 })
